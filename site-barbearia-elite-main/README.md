# Barbearia Elite

Sistema web para gerenciamento de uma barbearia, desenvolvido para facilitar o atendimento aos clientes e o gerenciamento de agendamentos.

O projeto conta com uma interface moderna e responsiva, permitindo que os clientes criem suas contas, visualizem os cortes disponíveis e agendem horários de forma simples e intuitiva.

## Funcionalidades
- Cadastro e login de usuários.
- Página inicial com galeria de cortes.
- Visualização de serviços e preços.
- Agendamento de horários.
- Seleção de barbeiros, datas e horários.
- Consulta de agendamentos.
- Validação de horários disponíveis.
- Confirmação de agendamentos.

## Tecnologias utilizadas

**Front-end**
- HTML5
- CSS3
- JavaScript

**Back-end**
- Python
- FastAPI

**Banco de dados**
- SQL (MySQL)

## Objetivo

Desenvolver uma aplicação web completa, integrando front-end, API REST e banco de dados relacional, aplicando conhecimentos de desenvolvimento web, programação back-end e gerenciamento de dados.
